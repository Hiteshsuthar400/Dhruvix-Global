# Assets / Images

This folder stores all images used by the website. Place image files here and commit them to the repository on the `add-default-home-and-bg` branch.

Recommended structure:

- assets/images/hero.jpg — main HD hero/background image (add your HD image here)
- assets/images/logo.png — site logo
- assets/images/products/ — product images
- assets/images/icons/ — small UI icons

Tips:
- Keep image filenames lowercase and use dashes (e.g., product-1.jpg).
- Optimize images for web (compress and resize) before committing to keep the repo size small.
- If you prefer not to store large images in the repo, host them on a CDN or Unsplash and reference external URLs in your HTML/CSS.
